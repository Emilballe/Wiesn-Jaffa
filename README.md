# WIESN-JAFFA 2026 — V2

V2 er bygget ud fra video-feedbacken:

- Ansigtet er fritlagt og har transparent baggrund i stedet for den firkantede fotoboks.
- Større karikeret hoved på en tegnet Lederhosen-krop.
- Løbeanimation/bob, bevægelige ben og arme.
- Tegnede pickups og figurer i stedet for emoji-sprites.
- Wiesn-bane med blå/hvide telte, blomster, lys, skilte og brosten.
- Pretzels +100, Maß +250, dirndl +500.
- Security tager 1 liv.
- 3 Maß i træk giver PROST MODE med 2x point i 10 sek.
- Stigende fart, partikeleffekter, lille skærmrystelse og simple lyde.
- Highscore gemmes lokalt.
- WASD/piletaster på desktop, touch-pad på mobil, P = pause.

## Sådan spiller du lokalt
Pak ZIP-filen ud og åbn `index.html` i Chrome/Edge/Safari.

## GitHub Pages
Upload hele indholdet til et public repository.
Gå til Settings → Pages → Deploy from branch → main → /(root).
